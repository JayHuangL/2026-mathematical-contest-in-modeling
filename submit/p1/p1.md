# 问题1：预热平衡阶段的温度与含水率

本目录是问题1的独立提交包。总体论文 ../paper.md 保持只读；本文件只整理其中问题1所需的假设、方程、数值方法、结果和复现材料。

## 1. 问题目标与数据

药材近似为长度 \(L=25\ \mathrm{cm}\)、半径 \(R=2\ \mathrm{cm}\) 的圆柱。初始温度为 \(28^\circ\mathrm C\)，初始干基含水率为 \(2.55\ \mathrm{kg/kg}\)。附件1给出 \(0\)--\(14400\ \mathrm{s}\) 的烘房温度和环境水分参考量，每60 s一个记录。

本问计算 \(0\)--\(1800\ \mathrm{s}\) 内药材内部的径向温度 \(T(r,t)\) 和干基含水率 \(C(r,t)\)，输出时间为100、300、600、900、1200、1500、1800 s，输出位置为距中心0、0.5、1、1.5、2 cm。

提交结果文件为 result1.xlsx：两个工作表分别保存温度和含水率，每1 s、每0.1 cm输出一次，共1800个时间行和21个径向位置。

## 2. 变量、参数与假设

径向坐标为 \(0\le r\le R\)，时间为 \(t\)。温度以摄氏度存储；水分浓度定义为

\[
C=\frac{m_w}{m_d},
\]

其中 \(m_w\) 为水质量，\(m_d\) 为干物质质量，因此 \(C\) 是干基含水率而不是单位体积水质量。

| 参数 | 数值 |
|---|---:|
| \(R\) | \(0.02\ \mathrm m\) |
| \(L\) | \(0.25\ \mathrm m\) |
| \(\rho\) | \(820\ \mathrm{kg/m^3}\) |
| \(c_p\) | \(2600\ \mathrm{J/(kg\cdot K)}\) |
| \(k\) | \(0.36\ \mathrm{W/(m\cdot K)}\) |
| \(h\) | \(25\ \mathrm{W/(m^2\cdot K)}\) |
| \(h_m\) | \(8\times10^{-7}\ \mathrm{m/s}\) |
| \(T_0\) | \(28^\circ\mathrm C\) |
| \(C_0\) | \(2.55\ \mathrm{kg/kg}\) |

主要假设如下：

1. 药材均匀、各向同性，忽略周向和轴向变化，只计算中段一维径向状态。
2. 第一问半径固定，热物性 \(\rho,c_p,k\) 为常数。
3. 忽略蒸发潜热、水分迁移携热、内部热源、变形功和端部效应。
4. 环境水分参考量直接进入有效 Robin 传质边界；这不是额外引入的严格气固平衡关系。

## 3. 边界输入：stretched_exp

### 3.1 候选方法和评价

对附件1的离散边界，比较了分段线性、PCHIP、Akima、自然三次样条、平滑样条和初值固定拉伸指数六类方法。评价指标为时间阻塞交叉验证 RMSE、最大绝对误差、曲线粗糙度和区间外越界。

两条边界均采用代码方法 stretched_exp。选择不是只按单一 RMSE：温度序列中它的 blocked hold-out RMSE 最低；含水率序列中自然三次样条的 RMSE 略低（约 4.13×10^-5 对 5.54×10^-5），但 stretched_exp 的粗糙度约为 7.30×10^-10，并由正参数直接保证单调性，且没有区间外越界。综合验证误差、平滑性、单调性、越界检查和两条边界使用同一可解释函数族的要求，主计算选用 stretched_exp。候选方法的完整指标见 boundary_cv.csv，拟合终点扫描见 boundary_endpoint_comparison.csv。

### 3.2 拟合函数

对任意边界量 \(y\)，固定 \(t=0\) 的观测初值 \(y_0\)，采用

\[
\boxed{
y(t)=y_0+A\left\{1-\exp\left[-\left(\frac{t}{3600\tau}\right)^p\right]\right\}
}.
\]

其中 \(t\) 的单位为秒，\(\tau\) 的单位为小时，\(A,\tau,p>0\)。主情景使用完整 \(0\)--\(14400\ \mathrm s\) 数据拟合：

\[
\boxed{
T_a(t)=28+22.0164003
\left\{1-\exp\left[-\left(\frac{t}{3600\times0.5233513}\right)^{1.1502893}\right]\right\}
},
\]

\[
\boxed{
C_a(t)=0.01963+0.03045648
\left\{1-\exp\left[-\left(\frac{t}{3600\times0.7508124}\right)^{1.2713644}\right]\right\}
}.
\]

| 边界量 | \(A\) | \(\tau\) / h | \(p\) | 拟合RMSE | 0--1800 s RMSE |
|---|---:|---:|---:|---:|---:|
| \(T_a\) / °C | 22.016400 | 0.523351 | 1.150289 | 0.1441934 | 0.1547982 |
| \(C_a\) / kg/kg | 0.03045648 | 0.750812 | 1.271364 | \(1.81827\times10^{-4}\) | \(2.88597\times10^{-4}\) |

拟合终点扫描显示：1800 s终点对早期 hold-out 更有利，但全窗口拟合的幅值和时间尺度更适合作为后续问题的共同环境边界，因此主情景选14400 s；其他终点作为敏感性情景保留。

## 4. 控制方程与边界条件

### 4.1 温度方程

沿径向的导热通量为 \(q_r=-k\,\partial T/\partial r\)。对半径为 \(r\) 的微小圆环做能量守恒，得到

\[
\boxed{
\rho c_p\frac{\partial T}{\partial t}
=\frac1r\frac{\partial}{\partial r}
\left(rk\frac{\partial T}{\partial r}\right)
},\qquad 0<r<R.
\]

等价地写成

\[
\frac{\partial T}{\partial t}
=\alpha\left(
\frac{\partial^2T}{\partial r^2}
+\frac1r\frac{\partial T}{\partial r}
\right),\qquad
\alpha=\frac{k}{\rho c_p}.
\]

### 4.2 含水率方程

附录2给出的扩散系数为

\[
\boxed{
D(C)=7\times10^{-9}\exp\left(-\frac{0.89}{C}\right)
}.
\]

以 \(j_w=-D(C)\,\partial C/\partial r\) 表示等效径向水分通量，对圆环做质量守恒，采用守恒通量形式：

\[
\boxed{
\frac{\partial C}{\partial t}
=\frac1r\frac{\partial}{\partial r}
\left(rD(C)\frac{\partial C}{\partial r}\right)
},\qquad 0<r<R.
\]

展开后
\[
\frac{\partial C}{\partial t}
=D(C)\left(C_{rr}+\frac1rC_r\right)+D'(C)C_r^2,\qquad
D'(C)=\frac{0.89}{C^2}D(C).
\]
因此不将 \(D(C)\) 移到微分算子之外，避免遗漏 \(D'(C)C_r^2\) 项。

### 4.3 初始与边界条件

\[
T(r,0)=28,\qquad C(r,0)=2.55.
\]

中心对称条件：

\[
T_r(0,t)=0,\qquad C_r(0,t)=0.
\]

表面采用有限速率交换：

\[
-kT_r(R,t)=h[T(R,t)-T_a(t)],
\]

\[
-D(C)C_r(R,t)=h_m[C(R,t)-C_a(t)].
\]

## 5. 数值求解

将径向区间划分为有限体积控制体。设第 \(i\) 个控制体边界为 \(a_i,b_i\)，去掉公共因子 \(2\pi L\) 后的几何权重为
\[
V_i=\frac{b_i^2-a_i^2}{2}.
\]
内部界面通量采用
\[
G^T_{i+1/2}=r_{i+1/2}k\frac{T_{i+1}-T_i}{\Delta r},\qquad
G^C_{i+1/2}=r_{i+1/2}D_{i+1/2}\frac{C_{i+1}-C_i}{\Delta r},
\]
其中 \(D_{i+1/2}\) 为相邻节点扩散系数的算术平均。于是
\[
\rho c_pV_i\dot T_i=G^T_{i+1/2}-G^T_{i-1/2},\qquad
V_i\dot C_i=G^C_{i+1/2}-G^C_{i-1/2}.
\]
中心界面取零通量，表面界面直接代入 Robin 条件；内部通量在相邻控制体求和时成对抵消，因此离散系统具有热量和水分守恒。

空间离散后得到刚性非线性常微分方程组，采用隐式 BDF 时间积分，并提供解析稀疏 Jacobian。主计算使用 \(N=6400\) 个径向区间；结果表按题目指定位置抽取，完整数据按1 s输出。

## 7. 误差、收敛与敏感性

空间网格加密结果如下：

| 区间数 \(N\) | 温度最大差 / °C | 含水率最大差 / kg/kg | 表格含水率最大差 |
|---:|---:|---:|---:|
| 800→1600 | \(7.05\times10^{-7}\) | \(1.90\times10^{-4}\) | \(1.39\times10^{-5}\) |
| 1600→3200 | \(1.76\times10^{-7}\) | \(4.69\times10^{-5}\) | \(3.48\times10^{-6}\) |
| 3200→6400 | \(4.39\times10^{-8}\) | \(1.17\times10^{-5}\) | \(8.71\times10^{-7}\) |

收紧 BDF 容差和时间步长后，全场最大时间离散差为 \(5.58\times10^{-9}\ ^\circ\mathrm C\)（温度）和 \(4.32\times10^{-9}\ \mathrm{kg/kg}\)（含水率）。有限体积热量和水分收支残差分别约为 \(10^{-14}\) 量级。

敏感性分析表明，换热系数 \(h\)、传质系数 \(h_m\) 和内部扩散系数 \(D\) 的影响可明显大于网格误差；因此四位小数是题目要求的输出格式，不应解释为同等物理精度。
