# 模型检验、合理性与误差分析

## 1. 检验范围与评价原则

本文模型给出了药材内部温度场、干基含水率场及全域干燥终点，但附件中没有独立的内部温度、内部含水率或失重观测。因此，当前能够严格完成的是数值验证、守恒检验、极限情形检验和物理合理性分析，尚不能把计算结果与实验真值比较并给出实验 RMSE。以下分析不再讨论环境数据预处理及拉伸指数拟合误差，只考察偏微分方程模型本身、数值求解误差、参数情景和模型简化的影响。

需要区分三个概念：网格差、时间步差和守恒残差属于数值误差或程序一致性指标；参数扰动得到的是给定范围内的情景敏感性；忽略潜热、端部传递和非均匀收缩等属于模型形式不确定性。后两者不能由很小的数值残差消除。

## 2. 数值正确性检验

### 2.1 空间网格与时间积分收敛

固定半径模型在相同物理时刻和输出位置比较相邻网格，第三、第四问还直接比较全域最大含水率达到临界值的事件时刻。时间误差则在主网格不变的条件下，将相对、绝对容差各收紧一个数量级，并减小最大内部步长。主要结果如下。

| 问题 | 空间加密检验 | 空间差异 | 时间收紧后的差异 |
|---|---|---:|---:|
| 第一问 | \(N=3200\to6400\) | 全场：\(T\) 为 \(4.43\times10^{-8}\ ^\circ\mathrm C\)，\(C\) 为 \(1.17\times10^{-5}\ \mathrm{kg/kg}\)；题目表格点的 \(C\) 差为 \(8.74\times10^{-7}\ \mathrm{kg/kg}\) | \(T\) 为 \(1.10\times10^{-8}\ ^\circ\mathrm C\)，\(C\) 为 \(4.32\times10^{-9}\ \mathrm{kg/kg}\) |
| 第二问 | \(N=300\to400\) | 全场：\(T\) 为 \(2.62\times10^{-6}\ ^\circ\mathrm C\)，\(C\) 为 \(7.53\times10^{-4}\ \mathrm{kg/kg}\)；表格点的 \(C\) 差为 \(1.87\times10^{-6}\ \mathrm{kg/kg}\) | \(T\) 为 \(5.00\times10^{-7}\ ^\circ\mathrm C\)，\(C\) 为 \(2.44\times10^{-8}\ \mathrm{kg/kg}\) |
| 第三问 | \(N=220\to300\) | 事件时刻相差 \(0.05635\ \mathrm s\)，60 s采样场最大差为 \(1.46\times10^{-5}\ \mathrm{kg/kg}\) | 事件时刻相差 \(0.002451\ \mathrm s\)，全场 \(C\) 最大差为 \(2.44\times10^{-8}\ \mathrm{kg/kg}\) |
| 第四问 | \(N=200\to300\) | 事件时刻相差 \(0.14888\ \mathrm s\)，实际位置输出最大差为 \(3.46\times10^{-5}\ \mathrm{kg/kg}\) | 事件时刻相差 \(0.01330\ \mathrm s\)，实际位置输出最大差为 \(1.84\times10^{-8}\ \mathrm{kg/kg}\) |

第二问全场含水率最大网格差出现在 \(t=1\ \mathrm s\) 的表面节点。初始时刻 Robin 边界迅速形成很薄的表面梯度，因此这一单点差异明显大于论文所列时刻和位置的差异；它没有传播成3 h结果的同量级偏差。分别报告全场最大差和表格点差，可以避免只选取有利指标。

各问的时间收紧误差均低于相应空间网格差。第三、第四问的终点是由连续事件定位得到，而每60 s保存一次结果只是输出要求，所以终点误差不受60 s采样间隔限制。主结果第三问为 \(57.67892564\ \mathrm h\)，第四问为 \(51.26821977\ \mathrm h\)；数值误差远小于报告到小数点后四位小时所对应的时间尺度。

### 2.2 Jacobian、退化情形与跨问题一致性

第二至第四问采用变物性耦合方程，Kirchhoff 水分通量及其端点导数被同时写入稀疏解析 Jacobian。用复步长方向导数进行独立检查，第二问和第四问的最大相对误差分别为

\[
4.02\times10^{-16},\qquad 3.02\times10^{-16},
\]

接近双精度浮点数的舍入水平，说明右端函数与解析 Jacobian 一致。第四问令 \(R(t)=R_0\)、改用附录3物性并采用均匀网格后，其方程右端与第二问的最大差为 \(3.00\times10^{-15}\)，验证了材料坐标方程在固定半径极限下能够退化到固定域模型。取消外部温湿驱动力时，均匀初始场的导数严格为零，说明坐标收缩没有被错误地当作热源或水分源。

第三问与第二问使用相同的方程和环境边界，仅将均匀网格换为表面加密网格并延长积分。在前3 h重叠区间，两者最大差为：温度 \(1.50\times10^{-5}\ ^\circ\mathrm C\)，含水率 \(7.74\times10^{-5}\ \mathrm{kg/kg}\)。该差异与两种网格及输出插值精度相符，没有出现跨问题的模型跳变。

### 2.3 水分守恒与结果文件检查

固定半径条件下，面积加权平均含水率满足

\[
\frac{\mathrm d\bar C}{\mathrm dt}
=\frac{2h_m}{R}\,[C_a(t)-C_s(t)].
\]

第四问采用干基含水率和材料坐标，守恒关系相应为

\[
\frac{\mathrm d\bar U}{\mathrm dt}
=\frac{2h_m}{R(t)}\,[C_a(t)-U_s(t)].
\]

将表面交换项随时间累计为 \(z(t)\)，定义绝对收支残差

\[
\varepsilon_C(t)=\bar C(t)-C_0-z(t).
\]

| 问题 | 最大绝对水分收支残差 / (kg/kg) | 相对于最终失水量的残差 |
|---|---:|---:|
| 第一问 | \(9.37\times10^{-16}\) | \(3.65\times10^{-15}\) |
| 第二问 | \(4.22\times10^{-15}\) | \(3.61\times10^{-15}\) |
| 第三问 | \(6.22\times10^{-15}\) | \(2.56\times10^{-15}\) |
| 第四问 | \(7.11\times10^{-15}\) | \(2.92\times10^{-15}\) |

残差均接近机器精度，表明有限体积内部通量能够成对抵消，表面边界、几何权重和累计量的符号一致。该检验说明离散程序内部自洽，但不代表计算结果已经得到实验验证。四个结果工作簿还经过逐单元格核对，均与按题意保留四位小数的结构化输出一致；四位小数带来的最大舍入误差为 \(5\times10^{-5}\)（对应变量单位），且不反馈到求解过程和终点判定。第三、第四问的事件判断使用另存的未舍入结果，报告时刻的全域最大含水率均严格小于 \(0.15\)；第四问位于当前药材半径外的固定位置保持为空白。

## 3. 物理合理性分析

### 3.1 变量范围与空间演化

四问计算过程中均有 \(C>0\)，且含水率不超过初始值 \(2.55\ \mathrm{kg/kg}\)。第一至第四问的最低含水率分别为1.5102、1.0075、0.05247和0.05243 kg/kg。温度均从28 °C开始，最高值分别为36.7806、49.8249、49.8858和49.8858 °C，没有在缺少额外热源时超过相应环境边界。

预热阶段表面先升温、先失水，随后温度和水分变化逐渐向中心传播。第三、第四问径向含水率的最大反向增量仅为 \(8.88\times10^{-16}\)，可视为浮点舍入误差；中心始终是最湿且最后达到阈值的位置。这与外表面对流换热、表面传质和内部径向扩散的方向一致，也说明采用全域最大含水率作为终点判据是必要的。

第四问半径曲线始终为正且主计算结束于附件2的观测时间范围内，没有使用半径外推。材料坐标把移动区域转化为固定区间；固定实际位置 \(r_j\) 先转换为 \(\xi_j=r_j/R(t)\)，再对同一时刻的含水率径向分布作 PCHIP 插值。该处理保持了计算节点的材料含义，也避免把已经位于药材外部的位置错误填成零含水率。

### 3.2 时间尺度的数量级检验

以第二问初始物性为例，计算得到

\[
Bi_T=\frac{hR}{k}\approx1.04,\qquad
Bi_M=\frac{h_mR}{D}\approx2.84,
\]

且热扩散率与水分扩散系数之比约为

\[
\frac{k/(\rho c_p)}{D}\approx25.7.
\]

第一问在1800 s时的热、湿 Fourier 数分别约为

\[
Fo_T=\frac{\alpha t}{R^2}\approx0.760,
\qquad
Fo_M=\frac{Dt}{R^2}\approx0.0222.
\]

这表明内部传热的时间尺度显著短于内部水分迁移，且水分表面交换与内部扩散均不可忽略。因此，后期温度很快接近均匀和稳定，而含水率仍保持明显的中心—表面梯度，是与无量纲量一致的物理结果。

## 4. 当前模型下重新计算的参数敏感性

敏感性分析均使用已经改为 Kirchhoff 水分通量的当前代码。每次只改变一个参数，其余参数保持主情景不变，故结果用于判断影响方向和相对重要性，不能解释为统计置信区间。本节不使用线性插值、拟合窗口或拟合残差情景。

定义中心差分形式的无量纲灵敏度

\[
S_{y,p}\approx
\frac{y(1.2p)-y(0.8p)}{0.4y(p)}.
\]

其绝对值越大，表示输出对该参数越敏感；符号表示参数增加时输出变化的方向。

### 4.1 第一问：预热阶段参数敏感性

第一问采用 \(N=800\) 的比较网格重新计算。参数改变20%时，1800 s平均量相对主情景的变化如下。

| 参数情景 | \(\Delta\bar T\) / °C | \(\Delta\bar C\) / (kg/kg) |
|---|---:|---:|
| \(h\times0.8\) | -0.7027 | 0 |
| \(h\times1.2\) | +0.5480 | 0 |
| \(h_m\times0.8\) | 0 | +0.03758 |
| \(h_m\times1.2\) | 0 | -0.03265 |
| \(D\times0.8\) | 0 | +0.00884 |
| \(D\times1.2\) | 0 | -0.00684 |

第一问温度与水分方程解耦，所以 \(h\) 只改变温度，\(h_m\) 和 \(D\) 只改变含水率。在给定扰动范围内，平均温度主要受换热系数控制，平均含水率对有效传质系数的敏感性高于内部扩散系数。降低 \(D\) 时表面补水变慢，表面局部含水率可能更低，但内部保持更多水分，故面积平均含水率反而升高；这不是符号错误，而是表面状态和整体失水量所反映机制不同。

### 4.2 第二问：变物性耦合参数敏感性

第二问使用当前 Kirchhoff 求解器、\(N=200\) 网格及与正式模型相同的时间容差重新计算。表中给出参数改变20%后，3 h平均温度和平均含水率相对基准值 \(49.8046\ ^\circ\mathrm C\)、\(1.38239\ \mathrm{kg/kg}\) 的改变量。

| 参数 | 乘以0.8：\(\Delta\bar T\) / °C | 乘以1.2：\(\Delta\bar T\) / °C | 乘以0.8：\(\Delta\bar C\) / (kg/kg) | 乘以1.2：\(\Delta\bar C\) / (kg/kg) | \(S_{\bar C,p}\) |
|---|---:|---:|---:|---:|---:|
| \(h\) | -0.09999 | +0.04052 | +0.00496 | -0.00336 | -0.0150 |
| \(h_m\) | -0.00877 | +0.00686 | +0.13025 | -0.10316 | -0.4221 |
| \(\rho c_p\) | +0.05693 | -0.10890 | -0.00468 | +0.00459 | +0.0168 |
| \(k\) | -0.02887 | +0.01603 | +0.00079 | -0.00053 | -0.00239 |
| \(D\) | -0.00442 | +0.00336 | +0.04659 | -0.03514 | -0.1478 |

3 h平均含水率的敏感性绝对值排序为

\[
h_m>D>\rho c_p\approx h>k.
\]

其中 \(h_m\) 增大使表面排湿能力增强，\(D\) 增大则加强内部水分向表面的补给，两者都会降低整体含水率。温度在3 h时已经接近稳定边界，所以参数变化对 \(\bar T\) 的绝对影响均不足0.11 °C；相对而言，\(\rho c_p\) 和 \(h\) 对升温过程影响最大。由于 \(D(T,C)\) 与温度耦合，改变热参数还会通过温度间接改变水分迁移，这解释了第二问中原本解耦的影响不再严格为零。

### 4.3 长期边界、收缩与物性情景

附件1只记录前4 h，而第三、第四问持续约50 h，因此尾段环境保持方式属于长期边界假设。当前 Kirchhoff 模型的情景结果如下。

| 模型与情景 | 达标时间 / h | 相对主情景变化 / h |
|---|---:|---:|
| 第三问主情景 | 57.67893 | 0 |
| 第三问尾段固定为50 °C、0.05 kg/kg | 57.47344 | -0.20548 |
| 第三问采用附件最后1 h均值 | 57.47514 | -0.20378 |
| 第四问主情景：附录4、PCHIP收缩半径 | 51.26822 | 0 |
| 第四问改用分段线性半径 | 51.27176 | +0.00354 |
| 第四问尾段固定为50 °C、0.05 kg/kg | 51.08888 | -0.17934 |
| 第四问附录4、固定半径 | 130.35882 | +79.09060 |
| 第四问附录3、保持收缩半径 | 25.31198 | -25.95624 |

第三、第四问尾段情景造成约0.18～0.21 h的变化，远大于毫秒至亚秒量级的时间积分和网格误差，说明长期边界假设是终点预测的主要不确定性来源之一。PCHIP改为线性半径只改变约0.00354 h，表明在现有采样密度下，半径插值方法对终点影响较小。

两个第四问结构对照还说明，收缩几何和附录物性都会显著改变时间尺度。固定半径对照只改变几何，附录3收缩对照只改变物性；二者影响均远大于半径插值误差。因此，不能把第三、第四问主结果的差异全部归因于“收缩使扩散距离缩短”，也不能把某一对照情景视为真实误差上下界。

## 5. 模型形式误差与适用范围

### 5.1 尚未计入的主要机制

主模型没有显式考虑蒸发潜热、水分迁移携带的焓、气相和液相的独立迁移、吸附平衡、孔隙率变化、开裂、轴向传热传质及端部效应。尤其是潜热可能显著降低表面温度并通过 \(D(T,C)\) 反向影响干燥速率，因而不能从上述很小的数值误差推断其影响可以忽略。

不过，当前 \(h_m(C_s-C_a)\) 是有效干基传质边界，并未由真实空气湿度、平衡含水率和水质量通量联合标定。直接把它乘以密度和汽化潜热会引入新的单位解释与干物质密度假设；把全部 \(C_t<0\) 当作局部汽化还会把内部水分重新分布重复计入相变。因此，现阶段只能把潜热列为模型形式不确定性，不能将某个未经标定的潜热扩展结果直接作为主模型的“误差修正值”。

### 5.2 几何和物性假设

一维径向模型假设圆柱轴向均匀并忽略端面交换；真实药材若长度与半径同量级，端部面积可能不可忽略，此时模型可能低估总换热和失水速率。第四问进一步假设长度不变、材料点保持相对径向位置、半径变化在截面内均匀。这些假设可以利用唯一的外半径记录封闭模型，但不能描述表层先收缩、内部滞后、局部开裂或孔隙塌缩。

经验物性 \(\rho(C),c_p(C),k(C),D(T,C)\) 被视为各节点的局部有效物性，其适用范围和材料批次误差没有由附件数据检验。第二问敏感性显示，水分预测对 \(h_m\) 和 \(D\) 尤其敏感，因此这两个参数的实验标定价值高于继续压缩已经很小的求解器误差。

## 6. 综合评价

| 评价层面 | 结论 |
|---|---|
| 数学与数值一致性 | 初边值条件完整，物性保持为正；网格、时间、Jacobian、事件定位和水分守恒检查均通过。 |
| 物理趋势 | 表面先响应、中心最后干燥，热扩散快于水分扩散，收缩与物性均能显著改变时间尺度，趋势与控制方程和无量纲分析一致。 |
| 参数稳健性 | 3 h含水率主要受 \(h_m\) 和 \(D\) 控制；长期终点还受4 h后的边界保持假设影响。参数扰动结果是情景范围，不是置信区间。 |
| 模型形式 | 潜热、气固平衡、端部效应和非均匀收缩尚未进入主模型，其影响可能大于数值误差。 |
| 实验验证 | 缺少独立内部温度、总质量和含水率观测，当前只能称为给定题设与假设下的机理预测，不能宣称已经验证真实预测误差。 |

综上，当前模型在数值层面已经达到稳定、守恒且可复现的要求，计算结果的有效位数不受网格和BDF时间误差控制。实际预测可信度主要取决于有效传质系数、扩散系数、长期环境边界以及潜热和收缩机制的合理性。若补充实验，宜优先采集完整干燥周期的总质量、中心与表面温度、空气湿度及半径变化，并用部分工况标定 \(h_m\) 和 \(D(T,C)\)，再以未参与标定的工况检验模型。
